Repositorio:
Un repositorio es un espacio donde se almacenan los archivos y cambios de un proyecto. Permite organizar la información y llevar un historial de modificaciones realizadas durante el desarrollo.

Commit:
Un commit es un registro de cambios realizados en un proyecto. Sirve para guardar una versión específica del trabajo y poder identificar qué modificaciones se hicieron.

Push:
El comando push permite enviar los cambios del repositorio local hacia GitHub. Esto ayuda a mantener el proyecto actualizado y disponible en línea.
