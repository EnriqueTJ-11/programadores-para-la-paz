Sistema operativo
Es el software que administra los recursos del computador y permite ejecutar aplicaciones. Proporciona el entorno donde funciona el servidor.

Node.js
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear servidores y aplicaciones web.

Aplicación server.js
Es el archivo que contiene la lógica del servidor. Define las rutas, respuestas y comportamiento de la aplicación.

Puerto
Es un punto de comunicación que permite recibir solicitudes de los usuarios. En esta práctica se utiliza el puerto 3000.

Logs
Son registros que almacenan información sobre la ejecución y eventos del sistema. Ayudan a detectar errores y monitorear el funcionamiento del servidor.
